# portland-plant-list
A simple web app to easily search the Portland Plant List. See if the plant in question in a native plant to the Williamette valley (the PPL is highly specific) OR if it is considered a nuisance invasive. Planting native plants creates invaluable habitats for insects, birds, and animals -- it's radical!

The Backyard Habitat Certification Program specifically looks for plants on this list (and NOT cultivars).

###Resources:
- [Backyard Habitat Certification Program](https://backyardhabitats.org/) 
- The full [Portland Plant List](https://backyardhabitats.org/wp-content/uploads/2018/03/Portland-Plant-List.pdf)
